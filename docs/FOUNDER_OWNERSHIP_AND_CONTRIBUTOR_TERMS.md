# Founder Ownership and Contributor Terms

## 1. Founder Ownership

Jifunze.ai is owned by Godfrey Maseno.

All original source code, platform architecture, database design, workflows, documentation, product strategy, learning model, course architecture, course structure, curriculum design, user experience design, mastery logic, certification logic, employable pathways, knowledge-engine design, deployment configuration, and related project assets created for Jifunze.ai are owned by Godfrey Maseno or the company/entity designated by Godfrey Maseno.

This ownership applies to the Jifunze.ai codebase, product concept execution, implementation history, architecture documents, course blueprints, learning workflows, migrations, tests, business workflows, and any related technical, product, or learning documentation stored in this repository.

## 2. No Implied Ownership by Contributors

Any code enhancement, bug fix, design update, documentation update, database migration, course update, curriculum support, testing work, deployment support, architecture review, course of consultation, or other contribution made by any developer, contractor, collaborator, instructor, course creator, assistant, advisor, AI-assisted tool operator, or third party does not create any ownership interest in Jifunze.ai.

Contributions do not give the contributor any right to claim ownership, co-ownership, equity, licensing rights, resale rights, content ownership, platform control rights, curriculum control rights, or decision-making authority over Jifunze.ai unless there is a separate written agreement signed or expressly approved by Godfrey Maseno.

## 3. Contract-Based Contributions Only

All work performed by third parties on Jifunze.ai is considered contract-based contribution work unless otherwise stated in a written agreement approved by Godfrey Maseno.

Such work may include, but is not limited to:

- Source code changes
- UI/UX improvements
- Database schema changes
- Supabase migrations
- Vercel deployment support
- Security review
- Documentation
- Product strategy support
- Testing and UAT support
- Bug fixes
- Feature enhancements
- Learning flow improvements
- Course content support
- Curriculum support
- Video/script/voiceover support
- Quiz or assessment support
- Certificate flow improvements
- Knowledge-engine support
- AI-assisted development support

None of the above creates ownership rights for the contributor.

## 4. Assignment of Work Product

To the fullest extent permitted by law, any project-specific work product created for Jifunze.ai by a contributor, contractor, collaborator, instructor, course creator, assistant, advisor, or third party is intended to be assigned to Godfrey Maseno or the company/entity designated by Godfrey Maseno.

Project-specific work product includes:

- Code

- Database migrations
- Documentation
- Architecture plans
- Course outlines
- Course materials
- Curriculum structures
- Lesson plans
- Quizzes
- Assessments
- Workbooks

- Tests
- Deployment workflows
- Product workflows
- Learning workflows
- Certification logic
- Business logic
- Configuration patterns
- Written implementation guidance
- Technical reports
- Security recommendations
- Feature specifications
- AI-assisted outputs created for the project

## 5. No Right to Reuse Proprietary Project Material

No contributor may copy, reuse, redistribute, sell, sublicense, disclose, publish, or repurpose Jifunze.ai proprietary code, workflows, architecture, database design, documentation, learning model, course structure, course materials, assessments, certification logic, knowledge-engine design, or business implementation without written authorization from Godfrey Maseno.

This restriction does not apply to general programming knowledge, publicly available open-source libraries, general teaching knowledge, or skills independently known by the contributor, but it does apply to Jifunze.ai-specific implementation, platform logic, learning architecture, curriculum structure, documentation, and project assets.

## 6. Third-Party and Open-Source Dependencies

Jifunze.ai may use third-party open-source libraries, frameworks, packages, tools, and services. Those third-party materials remain governed by their own licenses.

The use of open-source or third-party dependencies does not transfer ownership of Jifunze.ai’s original application code, architecture, documentation, learning workflows, course structure, business logic, or product implementation to any third party.

## 7. Repository Control

Control of this repository, related deployment accounts, Supabase projects, Vercel projects, domain configuration, documentation, course assets, and project assets remains with Godfrey Maseno or the company/entity designated by Godfrey Maseno.

Access granted to any person or tool is limited, revocable, and does not create ownership.

## 8. Written Agreement Required for Any Exception

Any exception to these terms must be documented in writing and expressly approved by Godfrey Maseno.

No verbal discussion, informal chat, code contribution, advisory support, pull request, commit, deployment help, course suggestion, curriculum suggestion, design suggestion, or technical assistance shall override this ownership position unless a separate written agreement clearly states otherwise.

## 9. Purpose of This Document

This document is stored in the Jifunze.ai repository to create a clear project record that:

- Godfrey Maseno is the owner of Jifunze.ai.
- Contributions are contract-based unless otherwise agreed in writing.
- Contributions do not create ownership claims.
- Enhancements, fixes, documentation, course work, curriculum support, and related work do not create equity or control rights.
- Project-specific work product belongs to Godfrey Maseno or the designated company/entity.
