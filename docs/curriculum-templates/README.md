# Curriculum content templates (Claude / author handoff)

These templates describe the structure Jifunze expects for self-learner-ready, evidence-oriented content. They are **not** filled lesson bodies—use them when generating or auditing long-form curriculum.

| Template | Purpose |
|----------|---------|
| `course-template.md` | Course-level outcomes, boundaries, capstone |
| `module-template.md` | Module arc, practice, checkpoints |
| `lesson-template.md` | Session-level blocks |
| `quiz-template.md` | Module quiz / checkpoint style |
| `capstone-template.md` | Final integrative work |
| `pathway-template.md` | Employability pathway framing |
| `portfolio-output-template.md` | Evidence learners can show |

Standards embedded in each template:

- Self-learner ready (clear next actions)
- Practical examples (realistic, region-agnostic unless labeled)
- Pause and check (self-check prompts)
- Practice task (doable without live instructor)
- Quiz/checkpoint (honest retrieval / judgment checks)
- Answer key or rubric (for self-review)
- Knowledge-to-output task (artifact-oriented)
- Completion evidence (what “done” means without over-claiming)
