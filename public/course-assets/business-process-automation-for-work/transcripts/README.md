# Business Process Automation for Work — transcripts

Optional plain-text or subtitle exports (e.g. `.txt`, `.vtt`) for download or accessibility can live here.

The in-app “Read transcript” panel uses text from `businessProcessAutomationNarration.ts` (`slideNarrations`) for each slide. When you publish standalone transcript files, you can set `transcriptDownloadUrl` in the narration manifest to a concrete file under this folder (for example `/course-assets/business-process-automation-for-work/transcripts/full-course.txt`) once that file exists.

Do not mark narration `ready` in code until matching audio files exist under `../audio/`.
