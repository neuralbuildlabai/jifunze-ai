# Jifunze training packages

Course and workshop material that lives in this repository. Each folder is self-contained: start from its own `README.md`.

## Contents

| Folder | What it is | Typical order |
|--------|------------|----------------|
| [`prompt-engineering-fundamentals/`](prompt-engineering-fundamentals/) | 30-minute prompt engineering course; optional Python examples | Standalone or first in the AI track |
| [`ai-agents-series/`](ai-agents-series/) | Three-part agents course (intro → memory/RAG → production/safety) | After prompt engineering; see that course’s “Next course” section |
| [`scrum-made-simple/`](scrum-made-simple/) | 35–45 minute Scrum micro-course / workshop | Independent of the AI courses |

## Paths

- From repo root, paths look like `training/<course-name>/`.
- API keys and secrets: use each package’s `.env.example` and never commit `.env`.
