# Business Analytics for Decision-Making

Professional micro-course assets for Jifunze.ai. The live interactive learner experience is published at **`/learn/free/business-analytics-decision-making`**.

## Contents

| Path | Purpose |
|------|---------|
| `business_analytics_decision_making_serious_deck.pptx` | 40-slide speaker deck with visuals listed in the course UI |
| `business_analytics_decision_making_source.md` | Companion notes, case framing, dataset summaries, and quiz reference |
| `quiz/` | Reserved for future markdown exports |
| `learner-exercise/` | Reserved for exported rubrics or templates |
| `assets/` | Reserved for CSV exports or diagram sources |
| `video-production/` | Reserved for future narration or video plans |

## Served downloads

The app links learner downloads from `public/training/business-analytics-decision-making/` (Vite static assets). After updating the deck or notes, copy refreshed binaries into that `public/` folder so production builds include them.
