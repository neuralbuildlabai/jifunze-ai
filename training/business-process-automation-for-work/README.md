# Business Process Automation for Work

Standalone Jifunze.ai professional micro-course / skill booster.

## Course positioning

Business Process Automation for Work teaches learners how to analyze a manual workflow, identify bottlenecks, calculate time and cost impact, choose automation opportunities, manage risk, and recommend a practical 30-day automation plan.

## Course type

Standalone professional micro-course / skill booster.

## Status

Course is live in the standalone learner catalog. Learner-facing configuration is implemented in `src/data/courses/businessProcessAutomationCourse.ts`. Route: `/learn/business-process-automation-for-work`.
